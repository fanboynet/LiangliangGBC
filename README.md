# LiangliangGBC
A GameBoy/GameBoy Color emulator written in Pascal(Delphi).

![cpu_instrs](./screen/cpu_instrs.png) ![mario](./screen/mario.png)

**Controls:**
- **W/A/S/D**: Up/Left/Down/Right
- **Z/X**: Select/Start
- **J/K**: Button A/B

**Compiler：**
- **Windwows(Delphi)**: dcc32 -B -Q .\GBEmuSDL.dpr
